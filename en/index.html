🤖 Software Engineering with AI

AI already reads repositories, edits files, runs tests, and reviews changes. The challenge is no longer getting AI to write code — it's getting AI to produce changes correct, safe, verifiable, and consistent with the architecture. This course teaches the engineering around the agent.

How to read: the course’s backbone, from left to right. The specification says what’s correct; the harness defines what the agent can do; the loop (in cyan) runs and corrects itself until it reaches the stopping condition; the quality gates decide whether the change can be released. Each track below explores one of these boxes in more depth.
